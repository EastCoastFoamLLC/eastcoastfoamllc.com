# 1. Executive direction

The best opportunity for East Coast Foam is **not** to become another generic "spray foam saves money" contractor website.

The strongest positioning direction is:

**problem-first education + honest diagnosis + existing-spray-foam second opinion + real project proof + easy estimate path**

ECF already has a meaningful differentiator that many contractor sites do not foreground:

> East Coast Foam audits/inspects spray-foam installations performed by other contractors.

That capability can become a trust anchor if Casey approves the public packaging.

The website should increasingly help a homeowner answer:

1. What am I noticing?
2. What could cause that symptom?
3. Does the problem appear related to insulation, air sealing, moisture, HVAC, drainage, roofing, or something else?
4. If I already have spray foam, does the installation deserve a closer look?
5. What would ECF inspect?
6. What options exist?
7. What happens next?

# 4. Second-opinion / inspection market research

Searches for "spray foam inspection" and "spray foam second opinion" return relatively few U.S. installer sites that make this a first-class homeowner service.

That does **not** prove the service is rare overall; it is a positioning hypothesis from public search observations.

Useful non-U.S. service-model references:

## SprayFoamCheck

Reference:
https://sprayfoamcheck.co.uk/services/spray-foam-inspection

Useful patterns:
- defined inspection scope;
- moisture readings;
- photos;
- report turnaround;
- clear statement of what the inspector does and does not sell.

ECF lesson:
A concrete deliverable makes "inspection" feel like a real service instead of a vague sales visit.

## National Spray Foam Advisory

References:
https://nationalsprayfoamadvisory.org/spray-foam-case-studies/
https://nationalsprayfoamadvisory.org/choosing-a-spray-foam-removal-company/

Useful patterns:
- second opinion before expensive removal;
- case studies where visible concern did not automatically mean removal;
- strong anti-pressure-sales framing;
- itemized decision support.

ECF lesson:
"Inspect before you remove or re-spray" is compelling trust language if Casey agrees with the operating model.

## Countrywide / second-opinion survey model

Reference:
https://countrywideinsulation.co.uk/services/spray-foam-removal/already-had-spray-foam-removed

Useful patterns:
- explicit "what we check";
- written report + photos;
- what needs doing / what does not;
- moisture readings;
- plain English.

ECF lesson:
If Casey already provides even a lighter version of this, we should define the deliverable clearly.

## FoamTruth

Reference:
https://foamtruth.com/spray-foam-inspection-before-removal/

Useful pattern:
- educate before removal;
- explain that inspection can answer a narrower question before destructive work.

Guardrail:
UK mortgage/removal issues are not directly transferable to South Carolina homeowner/lender practice.

# 5. What ECF can uniquely own

## A. "I already have spray foam"

Most insulation websites are optimized for:
- no insulation;
- old fiberglass;
- new construction;
- quote requests.

ECF can build a dedicated journey for:
**"I already paid for spray foam and I'm not sure it is right."**

That path can cover:
- performance concerns;
- visual defects;
- moisture/humidity;
- odor;
- home purchase;
- contractor dispute/uncertainty;
- repair vs add-to vs removal vs no action.

## B. Diagnose before selling

Proposed trust statement:

> We install spray foam, but an inspection does not start with the assumption that you need more foam.

Only publish after Casey approves the exact sentiment.

## C. Explain what insulation cannot fix

This is a major trust differentiator.

Examples:
- active roof leak;
- plumbing leak;
- bad drainage;
- standing crawl-space water;
- HVAC sizing/balance defect;
- duct leakage;
- missing moisture-control strategy;
- structural issue.

## D. Real corrective-work proof

If ECF has corrected another contractor's job, those case studies are uniquely valuable.

Case-study frame:
1. What homeowner noticed
2. What was installed
3. What ECF found
4. What was **not** wrong
5. Options
6. Corrective work
7. Photos
8. Result / follow-up

# 8. Roadmap scoring criteria

Before implementing a content idea, score it against:

- **Customer usefulness:** does it answer a real homeowner question?
- **ECF differentiation:** does it show knowledge/service competitors do not explain well?
- **Casey authenticity:** does it reflect how ECF really works?
- **Evidence quality:** can we support technical claims?
- **Search demand:** later informed by GSC/G.A.S.
- **Visual proof:** can real projects/diagrams make it clearer?
- **Conversion relevance:** does the page lead naturally to an appropriate next action?
- **Freshness burden:** how likely is it to become stale?
- **Risk:** safety/health/code/tax/warranty claim sensitivity.

Prefer high-usefulness / high-authenticity / high-evidence ideas over keyword volume.

# 10. Continuous-improvement hypothesis

ECF should aim to become the Lowcountry spray-foam website that is easiest to trust **before** the homeowner decides what they need.

Success is not "more pages."

Success looks like:
- homeowners find their symptom quickly;
- technical concepts become understandable;
- existing-foam owners see a legitimate second-opinion option;
- ECF openly states when foam is not the whole answer;
- real projects support the claims;
- Casey's field knowledge is visible;
- search/WQT/G.A.S. evidence refines priorities over time;
- the site remains fast, simple, local, and easy to contact.
